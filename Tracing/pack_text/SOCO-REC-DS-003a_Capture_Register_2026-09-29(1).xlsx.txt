=== SHEET: Read me
Capture register (SOCO-REC-DS-003a)
What this is | The single list of what the app, the backend and the recommendation service must capture, field by field. Updated 29 September 2026. The Wave 1A build list wins where the two differ. | Aravinth | For each of your rows, "What must be built" / "What the value must be" is the rule you have to code to. "How to check it is right" is how you will check your own work.
What is in it | 13 events, 80 fields and 12 data model changes, the Rules sheet that most rows point to, and sheet 4, which maps the platform's 26 native event types to the events. | Allen | Builds your rows (E1, served_items, the engine sync, ml_events) the same way, and reports status the same way.
How to read a row | Status says where it stood on 29 September 2026 (Verify = reported built in the APP-00 answers, check still to run). For a built row, Built on / due by is the build date. For rows still to build it is blank: the step each row sits in is in the Wave 1A build list, which also names the item (APP, DB or ENG) that builds it. What must be built / What the value must be is the rule to build and test against. Decided in lists the related codes in this register. | Run the code test. The test reads the register. Generate the schema file both sides build against from it.
Built | Reported built. Checked by the How to check column. | Report failures in two kinds: names missing from the register, or the test not being able to read the layout.
Verify | Reported built, one check still to run. | Aravinth | Keeps the register in step with the build list: dates every change in the Note, and adds rows only for new fields in the API contract.
To build | Accepted, not built yet. The step is in the Wave 1A build list.
Deferred | After Wave 1A. The consequence is in the Note.
Closed | Nothing to build: already captured or not needed.
Changing a row | Change it here and date the change in the Note. Any change to an event, a field or a retention period is agreed in writing by Allen and Aravinth first.
History | Earlier versions are withdrawn. This is the only version.
